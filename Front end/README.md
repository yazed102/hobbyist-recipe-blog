# Hobbyist Recipe Blog

## Brand direction
Hobbyist is positioned as a friendly recipe space for curious cooks: **Cook. Create. Make it yours.**

## Run locally
```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build
```bash
npm run build
```

The Vite root is `Front end/`, and the production output goes to `dist/`.
