# Hobbyist Recipe Blog - Milestone 1

## Requirements covered
- 4 distinct page views
- HTML5 semantic elements
- Bootstrap 5
- Responsive layout
- Home page with Recipe of the Day and categories
- Recipe Feed with recipe cards
- Recipe Detail with ingredients and step-by-step instructions
- Recipe Submission Form

## Team split
Person 1: index.html + shared navbar/footer design
Person 2: recipes.html + recipe cards
Person 3: recipe-detail.html + submit.html

Shared file: css/style.css
Before submission, merge the best styling from each person into the shared CSS.

## How to run
Open index.html in a browser, or use VS Code Live Server.
